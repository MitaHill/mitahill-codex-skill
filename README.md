# mitahill-codex-skill

个人维护的 Codex skills 集合，采用 `SKILL.md` 格式。

技能用途与分类见 [SKILLS.md](SKILLS.md)。系统预装的 `.system` skills 不包含在此仓库。

## 使用

将需要的单个 skill 目录复制到 `~/.codex/skills/`，或使用 Codex 的 skill installer 从本仓库安装。只安装实际需要的 skills，新增前请审阅其 `SKILL.md` 与任何附带脚本。

## 许可

各 skill 保留其原始许可证与归属；使用或再分发前请查阅对应目录中的许可说明。
